# CGPA Calculator in C++

## About the Project
This is a simple C++ console-based CGPA Calculator that calculates a student's CGPA based on the grade points and credit hours of multiple courses.

## Features
- Enter the number of courses.
- Input grade points for each course.
- Input credit hours for each course.
- Calculate total grade points and total credit hours.
- Calculate the final CGPA.
- Display the complete calculation results.

## Technologies Used
- C++
- iostream library

## How It Works
1. Enter the total number of courses.
2. Enter the grade points and credit hours for each course.
3. The program calculates the weighted grade points for each course.
4. It adds the total grade points and credit hours.
5. Finally, it calculates and displays the CGPA.

## Formula
**CGPA = Total Grade Points ÷ Total Credit Hours**

Where:

**Course Grade Points = Grade Point × Credit Hours**

## How to Run
1. Download or clone this repository.
2. Open `task1.cpp` in a C++ compiler or IDE.
3. Compile and run the program.
4. Enter the required course information.
